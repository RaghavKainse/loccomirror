## 🚀 Key Features

- **Direct3D 11 NV12 Hardware Acceleration**: Auto-detects and binds to discrete GPUs (NVIDIA GeForce, AMD Radeon, Intel Iris) for ultra-smooth 60 FPS presentation.
- **Sub-15ms Glass-to-Glass Latency**: Zero-copy GPU texture presentation pipeline.
- **OBS Studio Native Window Capture**: Fixed and optimized window rendering with true aspect-ratio preservation.
- **Compact Floating Toolbar**: Mini-controller dock with high-visibility active states (Pin on Top, Recording, Mute, Fullscreen).
- **Zero-Delay Auto Connection**: Automatic USB tunnel detection with background verification.
- **Automatic In-App Updates**: Seamless update checks and downloads directly in the application.

---

## 💻 System Requirements

- **Operating System**: Windows 10 (1809+) or Windows 11 (64-bit)
- **Graphics**: Direct3D 11 compatible GPU (NVIDIA, AMD, or Intel)
- **Phone Support**: Android 8.0 or higher with USB Debugging enabled
